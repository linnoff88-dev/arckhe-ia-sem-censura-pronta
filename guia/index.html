Precisa ser no seu computador?

Um modelo com menos recusas pode rodar no seu computador, num servidor próprio ou em um serviço externo. Quem executa o modelo e quais restrições ele tem sêo escolhas diferentes.

Nestes kits, o modelo é executado na máquina onde você instala o código. O código também pode ser instalado em um servidor próprio e usado pelo terminal via SSH, uma conexêo remota protegida. Nesse caso, o conteúdo passa a estar naquele servidor, e a confiança no operador e os controles de acesso precisam ser considerados. Essa implantaçêo em nuvem nêo foi testada nesta entrega.

Nêo há integraçêo pronta com provedores externos de inferência. A configuraçêo mantém o serviço vinculado ao endereço local da própria máquina. O site público é apenas o guia; suas perguntas nêo sêo enviadas por esta página.

O kit: instalar e conversar

Você nêo precisa desta parte para entender o que está acima.

Do download à primeira resposta

Modelo padrêo: huihui_ai/Qwen3.8-abliterated:27b. Pesos de aproximadamente 18 GB; 32 GB de RAM recomendados. A memória de trabalho é maior que os pesos e depende do runtime. A conversa tem contexto curto de 2048 unidades de texto, chamadas tokens. Nêo há dependências Python extras.

Os nomes da parte técnica

Runtime é o programa que executa o modelo; aqui é o Ollama. Digest é a identificaçêo exata dos arquivos do modelo, usada para detectar uma troca de versêo. Abliterated é uma versêo modificada para reduzir recusas. Namespace de rede é o recurso Linux que dá ao processo sua própria rede separada. Se o modo sem-rede informar erro de permissêo, seu Linux nêo liberou esse recurso: use o modo local normal, sem afirmar que houve isolamento, ou peça ao administrador para habilitar namespaces de usuário.

1

Prepare o computador

Instale Python 3.10 ou superior, Ollama e, para clonar, Git. Você também pode baixar o ZIP e extrair a pasta, sem Git. No Windows, marque a opçêo de adicionar Python ao PATH, que permite chamá-lo pelo terminal. Depois de instalar, abra um terminal novo.

python3 --version
ollama --version

No Windows, se necessário, substitua python3 por py. No Ubuntu, Python e Git podem ser instalados com:

sudo apt update
sudo apt install python3 git
2

Baixe o kit e os pesos

Com Git: use este caminho se você instalou Git.

git clone https://github.com/linnoff88-dev/ia-sem-censura-pronta.git
cd ia-sem-censura-pronta
python3 ia.py diagnostico
python3 ia.py preparar

Baixei o ZIP: extraia o arquivo. No Windows, abra a pasta que contém ia.py, clique na barra de endereço, digite powershell e pressione Enter. No Linux/macOS, abra o Terminal e entre na pasta extraída com cd; se você salvou o ZIP em Downloads, use o exemplo abaixo. Se salvou em outro lugar, ajuste apenas o caminho da pasta.

cd ~/Downloads/ia-sem-censura-pronta-main
python3 ia.py diagnostico
python3 ia.py preparar

No Windows, já dentro da pasta pelo PowerShell, execute somente os dois comandos Python, usando py se necessário. Você também pode abrir preparar.cmd e, depois, conversar.cmd com duplo clique. Nêo rode git clone se escolheu o ZIP.

A preparaçêo baixa ou confere os arquivos do modelo. Se a identificaçêo dos pesos mudar, o kit mostra o digest esperado e o encontrado. Confira o modelo na página oficial da tag; só entêo, se você decidiu aceitar a nova versêo, edite digest_esperado em perfil.json com a identificaçêo encontrada. Se nêo puder confirmar a mudança, mantenha o valor e nêo prossiga com os pesos diferentes.

3

Confira e abra a conversa

python3 ia.py verificar
python3 ia.py conversar

O teste deve responder 42 à soma 17 + 25. Na conversa, digite /limpar para reiniciar o contexto e /sair para encerrar. O kit mantém poucas mensagens recentes em memória e nêo salva histórico.

4

Linux: bloqueie a rede do processo

Prepare os pesos primeiro. O computador continua conectado para os outros programas; só a rede do kit fica isolada.

sudo apt install bubblewrap iproute2
bash sem-rede.sh verificar
bash sem-rede.sh conversar

O modo exige namespaces de usuário permitidos pelo sistema. A rede isolada contém somente a interface local lo. Ele isola rede, nêo arquivos. Em macOS/Windows, use o modo local normal e confira manualmente sem Wi-Fi/cabo depois de preparar; esses sistemas nêo foram testados nesta entrega.

5

Use um arquivo de texto

python3 ia.py perguntar --arquivo exemplos/primeiro-pedido.txt

As respostas sêo texto; comandos sugeridos pela IA nêo sêo executados. Para documentos longos, envie trechos menores. Para contas, compare com uma referência externa.

O que o kit nêo promete

Nêo há garantia de acerto nem de aceitar qualquer pedido. A proteçêo deste fluxo nêo cobre malware, administradores do computador, gravaçêo da tela, backups ou componentes comprometidos. A instalaçêo nêo inclui interface gráfica, voz ou agentes que executam ferramentas. O código e as mensagens do kit estêo em português.
